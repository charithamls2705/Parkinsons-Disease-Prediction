About the Model

Learn about the dataset, inputs, and model used by ParkinsonAI.

About the Project

This application provides voice-based Parkinson's disease prediction records for demonstration purposes. Each record includes an entry name, the predicted outcome, probability, and input values.

Dataset

The system uses the Parkinson's voice dataset and analyzes 22 speech-related features to support a prediction.

Input Features

The prediction uses 22 voice-related features such as pitch, jitter, shimmer, noise ratios, and nonlinear measures from the original Parkinson's dataset.

Machine Learning Model

The final selected model is a K-Nearest Neighbors (KNN) classifier. The Django app loads the saved KNN pipeline for prediction without retraining.

Model Performance

  • 5-fold cross-validation ROC-AUC: 0.9724184782608696
  • Test Accuracy: 0.8717948717948718
  • Test Precision: 0.9
  • Test Recall: 0.9310344827586207
  • Test F1-score: 0.9152542372881356
  • Test ROC-AUC: 0.9655172413793103

Model Probability

The model probability represents the probability estimated by the machine learning model for the predicted class. It does not represent medical certainty.
